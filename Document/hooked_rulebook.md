## 01 Overview & Philosophy

### What Is a Habit?
A habit is an **automatic behavior triggered by a situational cue**, encoded in the basal ganglia so it can be performed with minimal conscious thought. In product design, a habit is when a user reaches for your product **without deliberate decision-making**.

### Why Habit-Forming Products Win
| Advantage | Explanation |
|---|---|
| Lower CAC | Users return organically — no re-engagement spend |
| Higher LTV | Engaged users pay more and churn less |
| Pricing power | Users pay a premium to maintain routines |
| Defensible moat | Switching costs rise as investment grows |

### Vitamins vs. Painkillers
- **Vitamins** → Nice-to-have. People intend to use them but rarely do.
- **Painkillers** → Must-have. Solve an immediate, felt pain.
- **The goal:** Start as a vitamin, **become a painkiller** by creating a perceived pain that only your product relieves.

> *"The Hook Model is designed to connect the user's problem to the company's solution with enough frequency to form a habit."*  
> — Nir Eyal, Hooked (2014)

## 02 The Habit Zone

![The Habit Zone](assets/habit_zone_graph.png)

A product must achieve **sufficient frequency AND sufficient perceived utility** to enter the Habit Zone.

| Rule | Description |
|---|---|
| **HZ-01** | Assess how often the problem naturally occurs. Daily+ is ideal. |
| **HZ-02** | Perceived utility must exceed alternatives — not objective but shaped by experience. |
| **HZ-03** | Low-frequency products must compensate with very high perceived utility (e.g., TurboTax). |
| **HZ-04** | Before development, map your product on the Frequency × Utility grid. |

## 03 The Hook Model

![The Hook Model Cycle](assets/hook_model_cycle.png)

The Hook is a **four-phase repeating cycle** that, when completed repeatedly, programs automatic user behavior.

```
Trigger → Action → Variable Reward → Investment → [Next Trigger]
```

| Phase | Core Question | Goal |
|---|---|---|
| **⚡ Trigger** | What prompts the user to act? | Move from external to internal triggers |
| **👆 Action** | What is the simplest behavior? | Make it easier than thinking |
| **🎁 Variable Reward** | What satisfies the need? | Create craving through unpredictability |
| **💎 Investment** | What does the user put in? | Store value, load next trigger |

> ⚠️ **Critical:** Design for the 2nd, 10th, and 100th hook cycle — not just the first. Habits require repetition.

## 04 Phase 1 — Trigger

### External Triggers (4 Types)
| Type | Description | Example |
|---|---|---|
| **Paid** | Advertising, email campaigns | Facebook Ads, sponsored content |
| **Earned** | PR, viral media, App Store features | TechCrunch feature |
| **Relationship** | Word of mouth, social sharing, referrals | "My friend invited me" |
| **Owned** | Push notifications, email newsletters, app icons | Daily digest email |

### Internal Triggers
The ultimate goal — when a **feeling or situation** becomes the trigger:
- 😔 **Negative emotions** (most powerful): boredom, loneliness, fear, FOMO, uncertainty
- 🌅 **Situational cues**: morning routine, commute, lunch break
- ✅ **Positive triggers**: curiosity, creativity, motivation

### Trigger Rules
| Rule | Principle |
|---|---|
| **T-01** | Name the specific emotion before designing any trigger |
| **T-02** | Use the Five Whys to find the deepest pain point |
| **T-03** | Owned triggers must arrive when the internal trigger peaks |
| **T-04** | Make sharing a natural part of the product (relationship triggers = viral growth) |
| **T-05** | Measure every trigger type's conversion to action relentlessly |
| **T-06** | Track "organic open rate" as your internal trigger health metric |

## 05 Phase 2 — Action

### The Fogg Behavior Model: B = MAP

![Fogg Behavior Model](assets/fogg_behavior_model.png)

> **Behavior occurs when Motivation, Ability, and Prompt converge at the same moment.**

#### Motivation (3 Core Pairs)
- Sensation: Pleasure ↔ Pain
- Anticipation: Hope ↔ Fear
- Belonging: Social Acceptance ↔ Rejection

#### Ability (6 Simplicity Factors)
Minimize the **scarcest resource** for your user:

| Factor | Description |
|---|---|
| ⏱️ Time | How long the action takes |
| 💵 Money | Financial cost of the action |
| 💪 Physical Effort | Physical strain required |
| 🧠 Brain Cycles | Cognitive load / decisions required |
| 👥 Social Deviance | Does it align with social norms? |
| 🔄 Non-Routine | Does it disrupt existing habits? |

#### Key Heuristics That Boost Action
- **Scarcity Effect** — Limited availability raises perceived value
- **Framing Effect** — Context changes how choices are perceived
- **Anchoring Effect** — First number seen biases judgment
- **Endowed Progress** — Pre-showing partial progress boosts completion
- **Default Bias** — Pre-selected options dramatically increase adoption
- **Social Proof** — Others' behavior signals correct behavior

### Action Rules
| Rule | Principle |
|---|---|
| **A-01** | When in doubt, reduce friction — don't try to motivate |
| **A-02** | Identify the scarcest simplicity factor and eliminate it first |
| **A-03** | Core action must be achievable in under 30 seconds |
| **A-04** | Both motivation and ability must be above minimum thresholds |
| **A-05** | Make the ideal behavior the default state |
| **A-06** | Use endowed progress in onboarding (start progress bar at 20%) |

## 06 Phase 3 — Variable Reward

![Variable Rewards Types](assets/variable_rewards_types.png)

### The Neuroscience
Variable-ratio reinforcement (unpredictable reward timing) produces the **highest and most persistent behavior rates** (Skinner). The *anticipation* of reward activates dopamine more than the reward itself — which is why a slot machine is more compelling than a vending machine.

### Three Types of Variable Rewards

| Type | Driver | Examples |
|---|---|---|
| 👥 **Tribe** | Social validation, connection | Likes, comments, followers, leaderboards |
| 🔍 **Hunt** | Searching for resources/info | Infinite scroll, email inbox, deal discovery |
| 🏆 **Self** | Mastery, completion, achievement | XP, streaks, badges, progress bars |

### Variable Reward Rules
| Rule | Principle |
|---|---|
| **VR-01** | Reward must scratch the itch but leave room for more |
| **VR-02** | Variability must be authentic, not manufactured dark patterns |
| **VR-03** | Preserve user autonomy — rewards must not feel coercive |
| **VR-04** | Match reward type to the identified internal trigger emotion |
| **VR-05** | Stack all 3 reward types for resilience against disengagement |

## 07 Phase 4 — Investment

### The IKEA Effect
> People irrationally overvalue things they help create. Design features that let users "build" something in your product — even if imperfect, they'll value it more.

### Types of User Investment
| Type | Examples | Lock-In Power |
|---|---|---|
| ⏱️ Time | Profile customization, settings | Medium |
| 📊 Data | Uploaded files, preferences, history | High |
| 💪 Effort | Learning the interface, skill building | Medium |
| 🤝 Social Capital | Followers, reputation, connections | Very High |
| 💳 Money | Subscriptions, purchases | High |

### Investment Rules
| Rule | Principle |
|---|---|
| **I-01** | Every investment must improve the next experience — not just extract value |
| **I-02** | Start with micro-investments; escalate gradually |
| **I-03** | Make stored value visible to the user |
| **I-04** | Prioritize non-transferable investments (social capital, personalization) |
| **I-05** | Use commitment/consistency: one public action creates psychological momentum |

> ⚠️ **Investment MUST come AFTER the reward. Never before.**

## 08 Ethics & Manipulation Matrix

![Manipulation Matrix](assets/manipulation_matrix.png)

### The Two Questions
1. **Would I use this product myself?**
2. **Does this materially improve the user's life?**

### The Matrix

| | Improves Lives: YES | Improves Lives: NO |
|---|---|---|
| **Would Use: YES** | ✅ **Facilitator** — Ethical sweet spot | 🎭 **Entertainer** — Grey area |
| **Would Use: NO** | ⚠️ **Peddler** — Grey area (disconnect) | 🚫 **Dealer** — Exploitation |

### Ethics Rules
| Rule | Principle |
|---|---|
| **E-01** | Run every major design decision through the Manipulation Matrix |
| **E-02** | Measure user wellbeing, not just engagement metrics |
| **E-03** | Serve users' declared goals, not just their revealed preferences |
| **E-04** | Habits should enrich users' lives, not colonize them |
| **E-05** | Be transparent about persuasive design techniques |
| **E-06** | Give users meaningful controls to reduce engagement |

> 🚨 **AI Agent Checkpoint:** If a feature honestly falls outside the Facilitator quadrant, flag for human ethics review before proceeding.

## 09 Core Product Design Rules

| Rule | Category | Principle |
|---|---|---|
| **P-01** | Strategy | Name the specific emotion your product relieves before writing code |
| **P-02** | Strategy | Design the Hook cycle before designing features |
| **P-03** | Onboarding | Deliver a full Hook cycle in the first 5 minutes of first use |
| **P-04** | Retention | Each loop iteration should be easier than the last |
| **P-05** | Growth | Make sharing a natural part of receiving the reward |
| **P-06** | Metrics | Track Internal Trigger Rate, Hook Completion Rate, Investment Depth |
| **P-07** | Notifications | Every notification needs a one-sentence user value proposition |
| **P-08** | Investment | Personalization is the ultimate stored value |
| **P-09** | Psychology | Use loss framing for retention; gain framing for acquisition |
| **P-10** | Architecture | Build parallel Hook cycles for different user segments |

## 10 Brainstorm Criteria

Use these before investing development resources in any idea:

| # | Criterion | Question | Red Flag |
|---|---|---|---|
| BC-01 | Internal Trigger Clarity | Can you name a specific felt emotion? | "Anyone who wants to be productive" |
| BC-02 | Frequency Potential | Daily or multiple times per week possible? | Natural use is monthly or less |
| BC-03 | Action Simplicity | Core action under 30 seconds, minimal thinking? | Requires learning curve |
| BC-04 | Reward Variability | Is the reward genuinely unpredictable? | Same outcome every single use |
| BC-05 | Investment Mechanism | Does it improve with use? | Day 1 = Day 100 experience |
| BC-06 | Painkiller Test | Would users genuinely miss it? | Nice-to-have only |
| BC-07 | Ethical Alignment | Passes Manipulation Matrix? | Honest answer = outside Facilitator |
| BC-08 | Switching Cost | Non-transferable value created? | Zero friction to migrate to competitor |
| BC-09 | Viral Loop | Reward creates trigger for new users? | Sharing is an afterthought |
| BC-10 | Habit Zone Position | High frequency + high perceived utility? | Low on both axes |

## 11 Review Criteria

### Discovery Phase
- [ ] RC-01 — Specific, validated internal trigger identified from user research
- [ ] RC-02 — Product positioned in Habit Zone (frequency × utility)
- [ ] RC-03 — Full Hook cycle mapped from trigger through investment

### Design Phase
- [ ] RC-04 — Core action achievable in under 30 seconds from cold start
- [ ] RC-05 — All 6 Fogg simplicity factors reviewed and minimized
- [ ] RC-06 — At least one variable reward type designed
- [ ] RC-07 — Investment pathway that improves subsequent sessions designed

### Pre-Launch
- [ ] RC-08 — Onboarding delivers full Hook cycle in first session (tested)
- [ ] RC-09 — Owned triggers are personalized and opt-in
- [ ] RC-10 — All features evaluated against Manipulation Matrix
- [ ] RC-11 — User controls for reducing engagement designed in

### Post-Launch
- [ ] RC-12 — Internal Trigger Rate measured (% organic opens)
- [ ] RC-13 — Average investment depth per user after 30 days tracked
- [ ] RC-14 — Day-7, Day-30, Day-90 retention curves trending upward
- [ ] RC-15 — Sean Ellis Test: ≥40% say "very disappointed" if product disappeared

## 12 Master Hook Checklist

### ⚡ Trigger
- [ ] Specific internal trigger validated with user research
- [ ] At least 2 external trigger types designed and tested
- [ ] Owned triggers are timely, relevant, and opt-in
- [ ] Product linked to an existing daily routine
- [ ] Strategy to transition external → internal triggers exists
- [ ] Trigger effectiveness measurable and tracked

### 👆 Action
- [ ] Core action achievable in <30 seconds from trigger
- [ ] All 6 Fogg simplicity factors evaluated and minimized
- [ ] Zero unnecessary steps in action path
- [ ] Appropriate heuristics applied (social proof, scarcity, etc.)
- [ ] Default state = most desirable behavior
- [ ] Endowed progress visible during onboarding

### 🎁 Variable Reward
- [ ] At least one reward type (Tribe/Hunt/Self) designed
- [ ] Reward matches identified internal trigger emotion
- [ ] Reward satisfies the itch but leaves room for more
- [ ] Variability is authentic, not artificial
- [ ] User autonomy preserved during reward
- [ ] No coercive or dark-pattern reward mechanics

### 💎 Investment
- [ ] Investment occurs AFTER the reward
- [ ] Investment genuinely improves the next session
- [ ] Stored value is visible to the user
- [ ] At least some stored value is non-transferable
- [ ] Investment requests start small, escalate gradually
- [ ] Investment loads the next trigger

### ⚖️ Ethics
- [ ] Team would genuinely use the product themselves
- [ ] Product materially improves users' lives
- [ ] All features pass the Manipulation Matrix
- [ ] User wellbeing metrics tracked alongside engagement
- [ ] Product serves declared goals, not just revealed preferences
- [ ] Users have meaningful controls to reduce engagement
- [ ] No dark patterns in trigger/action/reward phases
- [ ] Vulnerable user populations considered

## 13 Real-World Hook Analysis

| Product | ⚡ Trigger | 👆 Action | 🎁 Variable Reward | 💎 Investment |
|---|---|---|---|---|
| **Instagram** | Boredom/FOMO + notification | Scroll feed | Tribe: likes, comments. Hunt: new posts | Photos, followers, location tags |
| **Twitter/X** | News curiosity + breaking news alert | Pull-to-refresh | Hunt: viral tweets. Tribe: replies/likes | Tweets, follower base, reputation |
| **Pinterest** | Need for inspiration (internal) | Infinite scroll | Hunt: visual discovery (always unpredictable) | Boards, pins, curated collections |
| **Duolingo** | "Lose your 30-day streak!" notification | 5-minute lesson | Self: XP, streaks, levels. Tribe: leaderboard | Streak, XP stored, course progress |
| **Slack** | Unread message badge | One tap to open | Tribe: reactions, direct replies, recognition | Message history, channels, integrations |
| **GitHub** | Professional identity / curiosity | Star, fork, explore | Self: contribution graph. Tribe: stars/followers | Code, repos, history, followers |
| **Spotify** | Need for focus/mood (internal) | Tap a playlist | Hunt: Discover Weekly. Tribe: Wrapped | Liked songs, playlists, listening history |
| **Amazon** | Need + convenience + deals notification | Search + 1-click buy | Hunt: deal discovery. Self: delivery satisfaction | Purchase history, saved payment, reviews |

### Counter-Examples (Where Hooks Failed)
- **Google+:** No distinctive trigger — users already had Facebook for social connection
- **Quibi:** Trigger crowded by YouTube/TikTok; premium content isn't variable enough
